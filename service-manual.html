What we offer

Add a paywall to any app in 2 minutes — without building auth, payments, or license backend.

• JavaScript SDK — 3 lines of code

• Cross-device sync — magic link login, restore purchases

What you don't need anymore

  • No backend for payments
  • No Stripe integration code
  • No auth system for license verification
  • No license storage or database
  • No webhooks setup

📦 JavaScript SDK

For web apps, Chrome extensions, React, Vue — anything that runs JS.

Installation

npm install sdk-2minpay

Usage (all you need)

import { init, isPaid, showPaywall } from "sdk-2minpay";

// Initialize SDK — shows Stripe onboarding if app not configured yet
await init();

// Check if user has access
if (!await isPaid()) {
  // Shows Stripe payment modal
  await showPaywall();
}

// User has access — load full app
loadApp();

SDK methods

  • init() — initializes SDK, shows developer onboarding on first run
  • isPaid() → true/false — checks if user has active access
  • showPaywall() — shows Stripe checkout modal

💰 Pricing

  • 2MinPay takes 5% + $0.30 per transaction
  • You set your monthly price (e.g., $9.99/month)
  • Payments go directly to your Stripe account

🔒 Security

  • isPaid() checks license status on 2MinPay servers — the response cannot be faked
  • If a user removes the if (!isPaid()) check — they can access the feature. This is true for any client-side product.
  • 2MinPay handles payment verification, license storage, and cross-device sync. You don't need a backend.

✅ For most extensions and apps, client-side isPaid() is enough. Protected content is only shown when user has paid or active trial.
