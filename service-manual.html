📦 JavaScript SDK

For web apps, Chrome extensions, React, Vue — anything that runs JS.

Installation

npm install sdk-2minpay

Usage - Web App (with bundler)

import { init, isPaid, showPaywall } from "sdk-2minpay";

// Initialize SDK — pass your email for Stripe onboarding
await init("developer@example.com");

// Check if user has access
if (!await isPaid()) {
  // Monthly subscription
  await showPaywall(2.99, true);  // $2.99 per month
  
  // Or one-time payment (lifetime access)
  await showPaywall(29.99, false); // $29.99 one-time payment, lifetime access
}

// User has access — load full app
loadApp();

Usage - Web App (without bundler)

<!-- Add import map to your HTML -->
<script type="importmap">
  {
    "imports": {
      "sdk-2minpay": "https://unpkg.com/sdk-2minpay@latest/dist/index.js"
    }
  }
</script>

<script type="module">
  import { init, isPaid, showPaywall } from 'sdk-2minpay';

  await init("developer@example.com");

if (!await isPaid()) {
// Monthly subscription — $2.99 per month
    await showPaywall(2.99, true);

// One-time payment — $29.99 lifetime access
    await showPaywall(29.99, false);
}

  // Load your app
  loadApp();
</script>

Usage - Chrome Extension (without bundler)

// 1. Copy the ESM file into your extension folder:
cp node_modules/sdk-2minpay/dist/index.js ./sdk-2minpay.esm.js

// 2. In manifest.json (Manifest V3), allow the API host:
"host_permissions": [ "https://api.2minpay.com/*" ]

// 3. In popup.html — one module entry (popup imports the SDK):
<script type="module" src="popup.js"></script>

// 4. In popup.js — same API as the web example:
import { init, isPaid, showPaywall } from './sdk-2minpay.esm.js';

await init("developer@example.com");

if (!await isPaid()) {
// Monthly subscription — $2.99 per month
    await showPaywall(2.99, true);

// One-time payment — $29.99 lifetime access
    await showPaywall(29.99, false);
}

SDK methods

  • init([email]) — initializes SDK, shows developer onboarding on first run. Pass email for faster Stripe onboarding
  • isPaid() → true/false — checks if user has active access
  • showPaywall(price, isSubscription = true) — shows Stripe checkout modal. isSubscription = true (monthly), false (one-time, lifetime access)

Developer gets paid access — the Stripe Connect account owner receives the payment.

💰 Pricing

  • 2MinPay takes 5% + $0.30 per transaction
  • Powered by Stripe. You keep full control of your money.
  • You set your price (one-time or monthly)
  • Payments go directly to your Stripe account

🔒 Security

  • isPaid() checks license status on 2MinPay servers — the response cannot be faked
  • License is verified on our servers.
  • Client-side checks can be bypassed — this is true for any JS app.
  • 2MinPay handles payment verification, license storage, and cross-device sync. You don't need a backend.

✅ For most extensions and apps, client-side isPaid() is enough. Protected content is only shown when user has paid or active trial.
